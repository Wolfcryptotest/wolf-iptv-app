# Wolf IPTV (Android)

Telefon, tablet ve Android TV için Xtream Codes IPTV oynatıcı.

- Canlı TV, Filmler, Diziler (sezon/bölüm uygulama içinde)
- Kategoriler ve Türkçe uyumlu arama
- ExoPlayer ile oynatma; canlıda `.ts` açılmazsa otomatik `.m3u8` dener
- Kanal değiştirme: oynatıcıda yukarı/aşağı kaydır, ◀◀/▶▶ düğmeleri, kumandada ↑/↓ veya CH+/CH−, gamepad'de LB/RB
- Android TV kumandası ve gamepad desteği, TV ana ekranında görünür

## İndirme
Her `main` güncellemesinde GitHub Actions APK'yı derler ve **Releases** bölümüne `WolfIPTV.apk` olarak koyar.
